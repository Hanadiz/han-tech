API Documentation

Use our REST API to manage your services, tickets, invoices, and more programmatically.

Authentication

All API requests require an API key. Generate your key from the API Keys section in your dashboard.

Include the key in the Authorization header:

Authorization: Bearer YOUR_API_KEY

Base URL: https://api.hantech.com/v1

Services

GET /services

List all available services.

curl -H "Authorization: Bearer YOUR_API_KEY" https://api.hantech.com/v1/services
GET /services/{id}

Get details of a specific service.

Tickets

GET /tickets

List all your support tickets.

POST /tickets

Create a new support ticket.

curl -X POST https://api.hantech.com/v1/tickets \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"subject":"Network issue","description":"Wi-Fi dropping every 30 mins","priority":"high"}'
GET /tickets/{id}

Get a specific ticket with all replies.

Invoices

GET /invoices

List all your invoices.

GET /invoices/{id}

Get a specific invoice with line items.

POST /invoices/{id}/pay

Pay an invoice.

Subscriptions

GET /subscriptions

List your active subscriptions.

PUT /subscriptions/{id}/upgrade

Upgrade a subscription to a higher plan.

DELETE /subscriptions/{id}

Cancel a subscription.

Certificates

GET /certificates

List your earned certificates.

GET /certificates/{id}/download

Download a certificate PDF.

JavaScript Fetch Example

fetch('https://api.hantech.com/v1/services', {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
})
.then(res => res.json())
.then(data => console.log(data));
